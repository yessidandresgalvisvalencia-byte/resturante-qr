## Prioridad técnica actual

La cadena económica que debe quedar impecable antes de ampliar alcance es:

**PEDIDO → VENTA → PRODUCTO → RECETA → INSUMO → INVENTARIO → COSTO → MARGEN**

Principios:

- datos confiables antes que inteligencia;
- cálculo determinístico antes que LLM;
- evidencia trazable antes que causalidad;
- Cerebro coordina; neuronas reportan;
- acciones sensibles requieren aprobación humana;
- profundidad en restaurantes antes que expansión multiindustria.
